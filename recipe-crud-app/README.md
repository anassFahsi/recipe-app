# React CRUD App

## 📌 Projektbeskrivning
En React-applikation som använder ett öppet API (DummyJSON Recipes API) för att utföra CRUD-operationer: skapa, läsa, uppdatera och ta bort recept. Axios används för API-anrop och React Router DOM för navigering.

## 👤 Författare
För- och efternamn: Anass Fahsi

## 🚀 Funktioner
- Skapa nya recept (Create)
- Lista alla recept (Read)
- Redigera recept (Update)
- Ta bort recept (Delete)
- Routing med minst 3 sidor
- Återanvändbara komponenter (minst 5)
- useState och useEffect används
- Loading- och error-hantering
